# LLM_Engineering

This folder contains practical experiments and notes for working with prompt design, prompting techniques, and applied LLM workflows.

## Contents

- `prompting_techniques.ipynb` — notebook exploring prompt engineering methods, examples, and templates for improving LLM outputs.

## Purpose

- Capture applied prompts, prompting patterns, and workflow ideas.
- Store notebooks that illustrate how to ask, format, and evaluate prompts with modern language models.
- Serve as a reference for experimenting with prompt structure and interaction style.

## Notes

- Use this folder for iterative prompt testing and design.
- Keep prompt examples and experiments self-contained so they can be reused across projects.
