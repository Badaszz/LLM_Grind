# LLM_Science

This folder includes research-style experiments, model analysis, and training workflows for sequence models and language models.

## Main sections

- `decoder_strategies.ipynb` — decoding strategy experiments and visualization.
- `full_seq2seq_pipeline.ipynb` / `full_seq2seq_pipeline.py` — end-to-end seq2seq training and inference workflows.
- `CBOW_pytorch.ipynb` / `RNN_pytorch.ipynb` — classic representation learning and recurrent model tutorials.
- `gpt2_analysis.ipynb`, `microgpt-badasz.ipynb`, `nanogpt-badasz.ipynb` — transformer experiments and small model analysis.
- `models/gpt2/` — locally saved GPT-2 model artifacts for offline use.
- `Preference_alignment/` — code and datasets focused on preference alignment and reward modeling.
- `Supervised_finetuning/` — fine-tuning workflows, data, and a personal Qwen2.5 assistant setup.
- `quantization/` — experiments and notes for model quantization.
- `decoding_strategies/` — utilities and experiments for beam search, top-k, nucleus, and other sampling methods.

## Purpose

- Support model experimentation, analysis, and training research.
- Collect notebooks and scripts for sequence modeling, decoding, and fine-tuning.
- Keep dataset, model, and experiment outputs organized for reproducibility.
