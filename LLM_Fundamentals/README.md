# LLM_Fundamentals

This folder contains foundational NLP notebooks and tutorials for classification, tokenization, and basic model workflows.

## Contents

- `NLP_classification.ipynb` — classification experiments and examples.
- `NLP_For_classification.ipynb` — additional classification-focused note taking and examples.
- `NLP_with_spacy.ipynb` — spaCy-based NLP pipeline examples and text processing demonstrations.

## Purpose

- Document core NLP concepts and fundamentals.
- Explore classification workflows, feature engineering, and model evaluation.
- Provide practical examples for understanding text pipelines and basic NLP tooling.
